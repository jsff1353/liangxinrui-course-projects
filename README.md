# 课程项目合集

本仓库收录三个独立的项目，分别位于以下目录：

| 目录 | 项目 | 技术栈 |
| --- | --- | --- |
| `file-batch-renamer/` | 文件批量重命名工具 | Python / Tkinter |
| `music-collection-platform/` | 音乐收藏平台 | Flask / Vue / Electron |
| `campus-trade/` | 校园交易平台 | Spring Boot / Vue |

每个目录均保留原项目的独立结构，可单独打开运行。各项目详细说明见其目录下的 README 或说明文档。

## 项目关键指标

以下指标均来自各项目源码与测试文档的实际统计。

### 1. `file-batch-renamer/` — 文件批量重命名工具

- **代码规模**：10 个 Python 源文件，约 1,954 行代码，采用 view / service / dao 三层分层。
- **核心能力**：支持「添加前后缀 + 字符替换 + 序号编号」三类规则叠加，预览与执行共用同一份重命名计划，保证所见即所得。
- **结果指标**：**1 键全量撤销** —— 每次批量重命名的成功项都逐条留痕，改错后一键即可完整还原。

### 2. `music-collection-platform/` — 音乐收藏平台

- **测试效果**：36 个黑盒接口用例全部通过（通过率 100%，系统功能缺陷 0 个），覆盖认证、歌单、歌曲、标签、管理后台等 6 个模块。
- **功能与数据规模**：提供 29 个 RESTful 接口、5 张数据表（4 业务表 + 1 关联表）；内置 8 首原创离线音频与 12 张 SVG 封面，断网即可完整演示。
- **结果指标**：**0 联网依赖** —— 8 首原创音频与 12 张封面全部内置，答辩现场断网也能完整演示试听、筛选与搜索。

### 3. `campus-trade/` — 校园交易平台

- **测试覆盖**：36 个 JUnit 5 单元测试（其中订单模块 14 个），覆盖防超卖并发、订单状态机、BCrypt 加密、AI 防幻觉核对等场景，Mockito 隔离数据库、无需启动 MySQL 即可运行。
- **代码规模**：86 个源文件，约 10,200 行代码（Java 4,494 行 + Vue 5,459 行 + JS 296 行）；AI 导购采用 Function Calling 多轮工具调用（最多 4 轮），无 API Key 时自动降级为本地检索。
- **结果指标**：**0 超卖** —— 下单用一条条件更新在数据库层杜绝超卖，未付款订单 120 分钟自动取消并释放商品。

---

## 1. 测试概述

### 1.1 测试目的

验证系统各功能模块是否满足《需求分析文档》中定义的功能性与非功能性需求，重点检查认证鉴权、数据增删改查、组合检索、权限隔离、管理员治理及数据一致性，确保系统可稳定用于演示与交付。

### 1.2 测试范围

- 用户模块：注册、登录、个人资料、退出、账号状态校验。
- 歌单/歌曲/标签模块：增删改查、组合筛选、关联关系。
- 管理后台：平台总览、用户管理、内容治理与安全约束。
- 数据一致性：删除操作的级联清理、演示数据完整性。
- 安全测试：未登录拦截、越权访问拦截、非法输入校验。

### 1.3 测试环境

| 项目 | 配置 |
| --- | --- |
| 操作系统 | Windows 10/11 (x64) |
| 后端 | Python 3.13 + `backend-dist/music-api.exe`（PyInstaller 打包产物） |
| 数据库 | SQLite 3（`%APPDATA%/music-collection-desktop/music_collection.db`） |
| 服务地址 | `http://127.0.0.1:5057/api` |
| 测试工具 | 基于 Python 标准库 `urllib` 的自研接口自动化脚本 |
| 业务基线 | 管理员 admin 预置演示数据：3 歌单 / 8 歌曲 / 6 标签 |

---

## 2. 测试方法与策略

采用**黑盒接口自动化测试**：测试脚本以 HTTP 请求直接调用后端 API，断言 HTTP 状态码与响应体 `code/message/data`。为避免污染演示数据，测试过程注册独立的临时测试账号（`qa*`）完成 CRUD，测试结束后由管理员接口删除该账号，并复核演示数据保持完整。

覆盖的测试类型：

| 类型 | 说明 |
| --- | --- |
| 功能测试 | 各接口正常流程是否符合预期 |
| 边界/非法输入测试 | 空值、超短密码、非法格式、重复名称 |
| 权限测试 | 未登录 401、越权 403、管理员专属接口 |
| 数据一致性测试 | 级联删除、歌单删除保留歌曲、标签删除解绑 |
| 回归验证 | 测试结束后演示数据完整性复核 |

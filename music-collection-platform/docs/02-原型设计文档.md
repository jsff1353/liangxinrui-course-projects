## 1. 设计目标与原则

### 1.1 设计目标

- 以"最低学习成本"组织个人音乐库：进入应用后立即看到自己的收藏概览。
- 用"歌单（纵向归类）+ 标签（横向标记）"二维模型，兼顾整理与检索。
- 管理员后台与普通用户界面风格统一，通过角色控制入口，减少认知负担。

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| 一致性 | 全站统一左侧导航 + 顶部标题栏 + 内容区的三段式布局 |
| 反馈性 | 所有操作均有成功/失败提示；危险操作有确认弹窗 |
| 容错性 | 表单做即时校验；空数据用插图与引导语提示 |
| 简洁性 | 主色为紫色（#7C6BF5），留白充分，避免信息过载 |

## 2. 信息架构

```
音乐收藏管理桌面平台
├── 公共区
│   ├── 登录页 /login
│   └── 注册页 /register
└── 主应用（需登录，左侧导航布局）
    ├── 概览 /home
    ├── 我的歌单 /playlists
    │   └── 歌单详情 /playlists/:id
    ├── 全部歌曲 /songs
    ├── 标签管理 /tags
    ├── 个人中心 /profile
    └── 管理后台 /admin （仅管理员可见）
        ├── 平台总览
        ├── 用户管理
        ├── 歌曲管理
        └── 歌单管理
```

路由采用 hash 模式（`createWebHashHistory`），以兼容 Electron 的 `file://` 加载方式；未登录访问受保护页面自动跳转登录页并携带 `redirect` 参数。

## 3. 全局布局原型

```
┌──────────────┬──────────────────────────────────────────────┐
│  ♪ 音乐收藏   │  概览                    [管理员] [头像 ▾]    │  ← 顶部标题栏 64px
│  MUSIC COLL.  ├──────────────────────────────────────────────┤
│              │                                              │
│  ⌂ 概览       │                                              │
│  ≡ 我的歌单    │              内容区（路由页面）                │
│  ♪ 全部歌曲    │                                              │
│  # 标签管理    │                                              │
│  ☺ 个人中心    │                                              │
│  ⚙ 管理后台*   │                                              │
│              │                                              │
│ 纯净·无广告    │                                              │
└──────────────┴──────────────────────────────────────────────┘
   侧边栏 216px              主内容区（可滚动）
   * 仅管理员角色显示
```

- **侧边栏**：Logo、菜单项（导航）、底部标语；管理员项按 `userStore.isAdmin` 条件渲染。
- **顶部栏**：当前页面标题、管理员标识、用户下拉菜单（个人中心 / 退出登录）。
- **内容区**：`<router-view>` 带淡入淡出过渡。

## 4. 核心页面原型

### 4.1 登录页 / 注册页

```
┌──────────────────────────────────────┐
│                                      │
│        ♪  音乐收藏                    │
│      MUSIC COLLECTION                │
│                                      │
│   欢迎回来 / 创建账号                  │
│   ┌──────────────────────────────┐   │
│   │ 用户名                        │   │
│   └──────────────────────────────┘   │
│   ┌──────────────────────────────┐   │
│   │ 密码                          │   │
│   └──────────────────────────────┘   │
│   （注册：昵称、邮箱）                 │
│        [ 登 录 / 注 册 ]              │
│   还没有账号？立即注册 / 已有账号登录   │
└──────────────────────────────────────┘
```

要点：用户名与密码必填；注册页含格式提示；登录成功后写入本地 Token 并跳转。

### 4.2 概览页 /home

```
┌──────────────────────────────────────────────────┐
│ 你好，{昵称} 👋        [管理歌单] [查看全部歌曲]   │  ← 渐变横幅
│ 今天是 2026年11月17日 星期二                       │
├──────────────┬──────────────┬──────────────┤
│ 我的歌单  3   │ 收藏歌曲  8   │ 自定义标签  6 │  ← 统计卡片
├──────────────┴──────────────┴──────────────┤
│ 最近收藏                        [查看全部 →]      │
│  [封面] River Flows In You - Yiruma  轻音乐 学习专注 │
│  [封面] 晴天 - 周杰伦            华语 单曲循环    │
│  ...（最多 6 条）                                │
└──────────────────────────────────────────────────┘
```

要点：三张统计卡反映真实数量；最近收藏显示封面、标签色块与时间；无数据时展示空状态引导。

### 4.3 我的歌单 /playlists

```
┌──────────────────────────────────────────────┐
│ 我的歌单                          [+ 新建歌单]  │
├───────────────┬───────────────┬──────────────┤
│ [封面] 深夜写代码 │ [封面] 通勤路上  │ [封面] 周末慢时光│
│ 安静、无歌词...   │ 随手收藏的...    │ 给自己的...     │
│ 3 首歌曲          │ 3 首歌曲        │ 2 首歌曲       │
│ [查看][编辑][删除]│ ...             │ ...           │
└───────────────┴───────────────┴──────────────┘
```

要点：卡片式歌单墙；显示歌曲数；删除操作二次确认；点击"查看"进入歌单详情。

### 4.4 歌单详情 /playlists/:id

```
┌──────────────────────────────────────────────┐
│ ← 返回   深夜写代码    3 首歌曲   [编辑歌单]     │
│ 安静、无歌词的专注歌单                          │
├──────────────────────────────────────────────┤
│ 歌曲列表（复用歌曲表格组件）                      │
│ 封面 | 歌名 | 歌手 | 标签 | 收藏时间 | 操作       │
└──────────────────────────────────────────────┘
```

### 4.5 全部歌曲 /songs（核心页）

```
┌──────────────────────────────────────────────────────┐
│ 全部歌曲   [关键词搜索框] [标签▾] [歌单▾] [+ 新增歌曲]    │
├──────────────────────────────────────────────────────┤
│ 封面│歌名│歌手│所属歌单│标签│收藏时间│试听 链接 编辑 删除   │
│ ▢  │River...│Yiruma│深夜写代码│轻音乐 学习专注│...│▶ ↗ ✎ ✕ │
│ ... 分页：‹ 1 2 3 ›                                  │
└──────────────────────────────────────────────────────┘
```

要点：
- 三类筛选栏并列，选择后立即刷新列表；
- 表格操作列：试听（有 url 才可用）、链接（有 url 才可用）、编辑、删除；
- 新增/编辑使用右侧抽屉或弹窗表单，含歌单下拉与标签多选。

### 4.6 标签管理 /tags

```
┌──────────────────────────────────────────┐
│ 标签管理                      [+ 新建标签]  │
│ [轻音乐 6] [华语 4] [学习专注 2] [治愈 3] ... │  ← 彩色标签块，显示引用数
│ 点击标签可编辑名称/颜色或删除               │

```

```
┌──────────────────────────────────────┐
│ 个人中心                              │
│ [头像] 昵称：{nickname}  角色：{role}   │

```

### 4.8 管理后台 /admin（仅管理员）

```
┌──────────────────────────────────────────────┐
│ 管理后台                                      │
├────────┬────────┬────────┬────────┤
│用户数 3│歌单数 3│歌曲数 8│标签数 6│  ← 平台总览卡片
├────────┴────────┴────────┴────────┤
```

要点：三类管理以标签页切换；用户搜索框；操作列含启用/禁用开关、角色切换、删除（二次确认）。

## 5. 核心交互流程

### 5.1 登录流程

```
游客 → /login → 输入用户名/密码 → POST /api/auth/login
   → code=0：保存 token+user → 跳转 /home（或 redirect 指定页）
   → code≠0：拦截器弹错误提示，停留登录页
```

### 5.2 新增歌曲流程

```
用户 → /songs → [新增歌曲] → 填写表单（标题/歌手/链接/封面/备注）
   → 选择所属歌单、勾选标签 → POST /api/songs
   → 成功提示 → 列表刷新（按创建时间倒序置顶）
```

### 5.3 删除歌单流程（保留歌曲）

```
用户 → /playlists → [删除] → 确认弹窗 → DELETE /api/playlists/:id
   → 后端将歌曲 playlist_id 置空 → 返回"歌曲已移至未分类"
   → 歌单消失，歌曲在"全部歌曲"中仍可见
```

### 5.4 管理员禁用用户流程

```
管理员 → /admin → 用户管理 → 搜索用户 → 切换"禁用"
   → PUT /api/admin/users/:id/status {status:0}
   → 该用户下次请求被 login_required 拦截，返回 403
```
